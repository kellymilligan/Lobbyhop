# Agents

**Integrating lobbyhop into a project?** Follow
[`skills/lobbyhop/SKILL.md`](skills/lobbyhop/SKILL.md). The guides in `docs/`
ship with the package: run `npx lobbyhop docs ls` and
`npx lobbyhop docs cat GUIDE.md`. Treat the installed package's docs as the
authority for its API.

**Working on lobbyhop itself?** Read [`CLAUDE.md`](CLAUDE.md): layout,
commands, conventions and how to verify changes.
